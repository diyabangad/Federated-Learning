## Prioritized Defects and Gaps

1. **P1: Energy parameters are not end-to-end calibrated.** TX/RX routing coefficients now feed an explicit communication/compute/residual ledger with preflight affordability checks. FL energy remains a separate proxy; integrate calibrated computation and FL communication costs into the satellite ledger and participation decision.
2. **P1: The traffic and metric schema is not an experiment simulator.** The TOML values are parsed but no arrival process creates packets, no deadlines/queues are enforced, and the listed PDR/lifetime/delay/throughput/control metrics are not computed. Implement these before interpreting baseline results.
3. **P1: Fuzzy logic differs materially from the proposal.** Implement all three 27-rule stages with specified membership functions, centroid defuzzification, member-to-head distance choice, and event-triggered reelection; then validate outputs across boundary and rule-coverage cases.
4. **P1: FL topology and protocol are absent.** Add cluster aggregation, gateway aggregation, contact-limited participation, staleness policy, and calibrated energy-aware admission; test hierarchy, partial participation, stale updates, and budgets.
5. **P2: Evaluation plan is absent.** Implement remaining baselines/ablations, at least ten seeded repeated trials, confidence intervals, significance tests, train/test distribution shifts, satellite failure, and generated tables/figures.
6. **P2: External model validation remains.** Current orbital tests verify period, geometry, and direct Skyfield consistency. Cross-check against an independent ephemeris/tool or published cases, and record data/source provenance.

## Immediate Recommendation

The Phase 0.5 defects are fixed. Phase 2 now has separate required routing TX/RX coefficients, a per-satellite communication/compute/residual ledger, preflight affordability checks for sender and receiver, hand-computed route delay metrics, and a contact planner with one-hop-per-slot and remaining-contact checks. Phase 3 adds a deterministic packet event prototype. FL energy remains a separate per-client proxy; finite buffers, MAC/channel effects, calibrated energy parameters, and repeated paper-scale evaluations remain open.

## Phase 0.5 Follow-up

- **Disconnected routing:** `_observation` catches `NetworkXNoPath` and `NodeNotFound`, encodes reachability in feature index 8, preserves feasible next-hop actions for potentially future contacts, and leaves drop as the only valid action when isolated. Tests cover isolated satellites, disconnected components, and a route that becomes reachable in a later snapshot.
- **DQN mapping:** `DQNPolicy` emits one score per candidate row plus one explicit learned drop value. `CentralizedDQNTrainer` masks invalid actions and computes the TD target from only valid next-state actions. Tests verify changing candidate counts, invalid action exclusion, drop selection, and masked target calculation.
- **Validation after fixes:** `python -m pytest -q` passed 26 tests; focused `test_next_steps.py` passed 15 tests.
